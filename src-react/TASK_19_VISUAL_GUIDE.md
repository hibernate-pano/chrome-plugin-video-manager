# 动画设置标签页 - 视觉指南

## 组件概览

AnimationTab 组件提供了直观的动画速度设置界面，让用户可以根据自己的偏好调整扩展的动画效果。

## 动画效果

### 1. 页面进入动画

```css
animate-in fade-in-50 duration-300
```

- 淡入效果
- 持续时间 300ms

### 2. 成功消息动画

```css
animate-in fade-in-50 slide-in-from-top-2 duration-300
```

- 淡入 + 从上方滑入
- 持续时间 300ms

### 3. HUD 预览动画

根据选择的速度动态调整：

- **正常**: `duration-300` (300ms)
- **快速**: `duration-150` (150ms)
- **关闭**: `duration-0` (0ms)

动画效果：
```css
transition-all ${duration}
opacity-0 scale-95 → opacity-100 scale-100
```

### 4. 悬停动画

```css
transition-all
```

- 所有属性平滑过渡
- 默认持续时间（150ms）

### 4. prefers-reduced-motion 支持

- 组件说明了系统级别的动画偏好设置

## 使用场景

### 场景 1: 首次访问

用户首次打开动画设置标签页：
1. 看到"正常"选项被选中（默认值）
2. 阅读每个选项的说明
3. 点击"播放预览"查看效果
4. 根据偏好选择合适的速度

### 场景 2: 更改设置

用户想要加快动画速度：
1. 点击"快速"选项卡片
2. 看到成功消息："动画速度已设置为：快速"
3. 点击"播放预览"查看新的动画效果
4. 设置自动保存到 Chrome Storage

### 场景 3: 关闭动画

用户在低性能设备上使用：
1. 点击"关闭"选项卡片
2. 看到成功消息："动画速度已设置为：关闭"
3. 点击"播放预览"，动画立即显示和隐藏（无过渡）
4. 所有扩展动画效果被禁用
