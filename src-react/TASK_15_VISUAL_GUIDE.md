# 任务 15 视觉效果指南

## 如何查看设置页面

### 方法 1：开发模式
```bash
cd src-react
npm run dev
```
然后在浏览器中访问：`http://localhost:5173/options.html`

### 方法 2：构建并加载扩展
```bash
cd src-react
npm run build
```
然后在 Chrome 中：
1. 打开 `chrome://extensions/`
2. 启用"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `src-react/dist` 目录
5. 点击扩展图标或右键选择"选项"

- **主背景**: `bg-gray-50` (浅灰色)

- **文字颜色**:

  - 次要文字: `text-gray-600`
  - 辅助文字: `text-gray-500`

- **最大宽度**: `max-w-4xl` (1024px)
- **内边距**:

  - 平板: `sm:px-6`
  - 桌面: `lg:px-8`

- **链接悬停**: `hover:text-gray-900` (颜色变深)

## 语言切换效果

点击语言选择器下拉框：
```
┌─────────────────┐
│ 🌐 English      │
│ ┌─────────────┐ │
│ │ English     │ │ ← 当前选中
│ │ 简体中文    │ │
│ └─────────────┘ │
└─────────────────┘
```

选择"简体中文"后，语言状态会：
1. 更新到 Zustand store
2. 自动持久化到 Chrome Storage
3. 触发 UI 更新（当国际化实现后）
