## 组件结构

### 1. 使用指南卡片

每个卡片包含：
- **编号徽章**: 圆形背景，白色数字
- **标题**: 粗体文字
- **内容列表**: 带项目符号的步骤或功能

**颜色方案**:
```
卡片 1: from-blue-50 to-indigo-50 + border-blue-200
卡片 2: from-purple-50 to-pink-50 + border-purple-200
卡片 3: from-green-50 to-emerald-50 + border-green-200
卡片 4: from-orange-50 to-amber-50 + border-orange-200
```

### 2. FAQ 项目

**折叠状态**:
```
┌─────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────┘
```

**展开状态**:
```
┌─────────────────────────────────────────────────────┐
```

- 悬停时背景变为 `bg-gray-50`

## 响应式设计

### 桌面视图 (≥640px)
- 使用指南：2列网格布局
- FAQ：全宽单列
- 联系按钮：水平排列

### 移动视图 (<640px)
- 使用指南：单列堆叠
- FAQ：全宽单列
- 联系按钮：垂直堆叠

## 动画效果

### 页面进入
```css
animate-in fade-in-50 duration-300
```
整个标签页淡入，持续 300ms

### FAQ 展开
```css
animate-in fade-in-50 slide-in-from-top-2 duration-200
```
答案区域淡入并从上方滑入，持续 200ms

### 箭头旋转
```css
transition-transform
rotate-180 (展开时)
```
平滑的旋转动画

### 主要颜色
- **蓝色**: 信息提示、快速开始

## 可访问性

### 键盘导航
- FAQ 项目可通过 Tab 键导航
- Enter/Space 键可展开/收起
- 链接可通过键盘访问

### 语义化 HTML
- 使用 `<section>` 组织内容
- 使用 `<h2>`, `<h3>`, `<h4>` 层次结构
- 使用 `<kbd>` 标记快捷键
- 使用 `<button>` 而非 `<div>` 处理点击

### ARIA 属性
- 按钮有明确的文本标签
- 链接有 `rel="noopener noreferrer"`
- 图标有适当的 `aria-label`（如需要）

## 性能考虑

### 优化措施
1. **按需渲染**: FAQ 答案仅在展开时渲染
2. **CSS 动画**: 使用 GPU 加速的 transform
3. **图标优化**: 使用内联 SVG 减少请求
4. **响应式图片**: 根据屏幕大小调整布局

### 包大小影响
- 新增组件约 5KB (未压缩)
- 无额外依赖
- 使用现有的 Tailwind 类
