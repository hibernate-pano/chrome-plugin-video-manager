## 交互流程

### 添加预设流程
```
1. 点击"添加预设"按钮
   ↓
2. 显示添加表单（淡入动画）
   ↓
3. 输入速度值
   ↓
4. 点击"确认添加"
   ↓
5. 验证输入
   ├─ 有效 → 添加预设 → 显示成功消息 → 隐藏表单
   └─ 无效 → 显示错误消息
```

### 编辑预设流程
```
1. 点击编辑按钮
   ↓
2. 卡片切换到编辑模式
   ↓
3. 修改速度值或快捷键
   ↓
4. 点击"保存"
   ├─ 有效 → 更新预设 → 退出编辑模式
   └─ 无效 → 显示错误提示
```

### 删除预设流程
```
1. 点击删除按钮
   ↓
2. 显示确认对话框
   ├─ 确认 → 删除预设 → 从列表移除
   └─ 取消 → 关闭对话框
```

## 性能优化

### 渲染优化
- 使用 React.memo 缓存 PresetCard
- 避免不必要的重渲染
- 使用 key 优化列表渲染

### 动画优化
- 使用 CSS transform 和 opacity
- 避免触发重排
- GPU 加速动画

### 状态管理
- Zustand 轻量级状态管理
- 自动持久化到 Chrome Storage
- 按需订阅状态更新
