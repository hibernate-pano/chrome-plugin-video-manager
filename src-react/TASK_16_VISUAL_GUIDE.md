## 交互流程

### 设置快捷键流程
```
1. 用户点击输入框
   ↓
2. 进入录制模式（蓝色边框 + 录制指示器）
   ↓
3. 用户按下按键
   ↓
4. 系统检测冲突
   ├─ 无冲突：显示按键，退出录制模式
   └─ 有冲突：显示按键 + 红色警告
   ↓
5. 用户点击"保存设置"
   ├─ 有冲突：显示错误提示，禁止保存
   └─ 无冲突：保存到 Chrome Storage，显示成功提示
```

### 重置快捷键流程
```
1. 用户点击"重置为默认"
   ↓
2. 显示确认对话框
   ├─ 取消：关闭对话框
   └─ 确定：重置所有快捷键为默认值
```

## 颜色方案

### 状态颜色
- **正常**: 灰色边框 (#e5e7eb)
- **焦点**: 蓝色边框 (#3b82f6)
- **录制**: 蓝色边框 + 蓝色环 (#3b82f6)
- **冲突**: 红色边框 + 红色背景 (#ef4444, #fef2f2)
- **成功**: 绿色图标 + 文字 (#10b981)
- **错误**: 红色图标 + 文字 (#ef4444)

### 按钮颜色
- **主按钮**: 蓝色背景 (#2563eb)
- **次按钮**: 白色背景 + 灰色边框
- **禁用**: 灰色背景 + 50% 透明度

- Tab: 在输入框之间导航

### 3. 视觉反馈
- 焦点状态有明显边框
- 冲突状态有颜色和图标
- 保存状态有图标和文字
- 录制状态有指示器

## 技术实现亮点

### 1. 实时冲突检测
- 使用 Map 数据结构存储冲突关系
- O(n) 时间复杂度检测所有冲突
- 实时更新冲突状态

### 2. 乐观更新
- 本地状态立即更新
- 异步保存到 Chrome Storage
- 失败时回滚状态

### 3. 防抖处理

- 避免闪烁和性能问题

### 4. 类型安全
- 完整的 TypeScript 类型定义
- 编译时类型检查
- IDE 智能提示
