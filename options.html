使用说明 Instructions

本插件允许您使用自定义快捷键控制网页上视频和音频的播放速度。 This extension allows you to control video and audio playback speed using custom shortcuts.

基本使用方法 Basic Usage

  • 插件会自动检测当前页面上的视频或音频元素 Extension automatically detects video or audio elements on the page
  • 使用设置的快捷键直接控制媒体播放 Use configured shortcuts to control media playback
  • 更改播放速度时，会显示速度指示器 Speed indicator will appear when changing playback speed

视频选择逻辑 Video Selection Logic

  • 插件优先控制您鼠标悬停的视频/音频 Extension prioritizes video/audio under your mouse cursor
  • 如果没有悬停，则选择最近交互过的媒体 If no hover, selects most recently interacted media
  • 如果有多个播放中的媒体，优先选择视口内最大的 If multiple playing media, prioritizes largest in viewport

网页全屏模式特殊功能 Fullscreen Mode Special Features

  • 在网页全屏模式下，可使用方向键控制视频： In fullscreen mode, you can use arrow keys to control video:
  • ← 左方向键：快退5秒 ← Left Arrow: Rewind 5 seconds
  • → 右方向键：快进5秒 → Right Arrow: Forward 5 seconds
  • ↑ 上方向键：增加音量 ↑ Up Arrow: Increase volume
  • ↓ 下方向键：减小音量 ↓ Down Arrow: Decrease volume
  • ESC键：退出网页全屏模式 ESC key: Exit fullscreen mode

注意事项 Notes

插件的快捷键只在有视频或音频元素可用时才会拦截。如果页面上没有媒体元素，快捷键会正常传递给页面。 Shortcuts are only intercepted when video or audio elements are available. If no media elements are on the page, shortcuts will pass through normally.

在网页全屏模式下，您可以按ESC键退出全屏。 In page fullscreen mode, you can press the ESC key to exit fullscreen.
