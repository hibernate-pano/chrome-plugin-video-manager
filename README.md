# Video Speed Controller — Fullscreen & Keys

一个极简的 Chrome MV3 网页视频工具，只做三件事：

- **网页全屏**：把任意网页里的视频铺满视口，配一条会自动隐藏的极简控制条
- **播放速度**：快捷键加速 / 减速 / 重置
- **播放控制**：播放/暂停、快进快退

没有弹窗、没有多余设置项。装完即用，用完即忘。

调速时会短暂冒出一个速度胶囊；1 秒后它淡出，几秒后在视频角落留下一枚很淡的
小角标（不可点击，绝不挡住你点视频），这样你随时都知道当前是几倍速。不想看它，
把视频暂停、把视频滚出视口，或者进全屏，它就会消失 —— 进全屏后控制条上本来就
写着倍速，不需要再来一个。

> 这是整个扩展里唯一一处常驻界面。它换来的是「当前几倍速随时可见」——
> 控制条 3 秒就隐藏，而非全屏时没有任何别的地方会告诉你现在是几倍速。

## 默认快捷键

| 功能 | 快捷键 |
| --- | --- |
| 加速（+0.1，长按连续） | `=` |
| 减速（-0.1，长按连续） | `-` |
| 重置速度 | `0` |
| 播放 / 暂停 | `Space` |
| 快退 5 秒 | `←` |
| 快进 5 秒 | `→` |
| 网页全屏 | `f` |

- 全屏内 `Escape` 退出网页全屏
- 每个键都可以在设置页改绑；留空即禁用该动作
- 点击工具栏图标 = 切换当前标签页的网页全屏
- 打开设置页：`Ctrl+Shift+,`（macOS 上是 `⌘⇧,` —— Chrome 会把 `Ctrl` 自动翻译成
  `Command`；也可在 `chrome://extensions/shortcuts` 里改成你顺手的键，
  或右键扩展图标 → 选项）
- 工具栏图标的悬停提示会显示该标签页当前的倍速

## 网页全屏

- 自动选中页面上"你正在看的那个视频"（打分制：播放中 > 可见 > 在视口 > 面积）
- 字幕等浮层跟着视频一起进出全屏（兼容沉浸式翻译等插件生成的字幕）
- 优先把视频搬进独立容器（reparent），失败时退回 CSS cover 兜底
- 全屏内有一条极简控制条：播放/暂停、进度（可拖）、时间、音量、倍速、退出
- 控制条在鼠标静止 3 秒后自动隐藏，移动鼠标即浮现
- 退出时完整还原页面布局；页面重排 DOM 也不会把视频卡死在全屏里

## 不打扰的反馈

- 调速时视频角落淡入一个 `1.5x` 小胶囊，约 1 秒后淡出——全屏内外都显示；
  胶囊淡出后会**留下**一枚很淡的小角标，直到视频暂停、滚出视口或进入全屏
- 控制条 3 秒无操作即隐藏，不能指望它承担键盘调速的反馈
- **不接管你没在看的视频**：快捷键只作用于你正在看的那个。多视频页面且无法
  确定对象时，扩展完全让路——宁可什么都不做，也不要接管错对象
- **不记忆速度**：任何视频都从 1.0x 开始。网课要 2.0x、纪录片要 1.0x，
  这个选择留给你当场按，而不是变成一条你看不见的默认规则

## 无障碍

- 调速、首次引导、接管失败提示都有**读屏播报**通道（视觉上不可见的 live region）
- 控制条可完全用键盘操作：方向键调步长、`Home`/`End` 跳首尾、`Esc` 关闭菜单
- 尊重系统的「减少动效」设置（`prefers-reduced-motion`）

## 本地开发

```bash
pnpm install
pnpm build
```

加载扩展：

1. 打开 `chrome://extensions/`
2. 开启"开发者模式"
3. 选择"加载已解压的扩展程序"
4. 指向项目的 `dist/` 目录

## 测试

```bash
pnpm test          # 单元测试（jsdom + chrome mock）
pnpm build         # tsc 类型检查 + vite 构建 → dist/
pnpm test:e2e      # 全部 Playwright（会先 build）
pnpm test:e2e:ext  # 真加载 dist 的 E2E（会先 build，需要本机有 Chromium）
```

CI 会在 push / PR 上跑 `test`、`build` 和 `e2e` 三个 job（`build` 依赖 `test`，`e2e` 独立）。出包不再走 CI，改由本地 `pnpm build:ext` 完成。

## 当前边界

- 只控制 `video`，不覆盖 `audio`
- 跨域 iframe 内的视频无法直接接管（**同源** iframe 可以）
- DRM 视频（如 Netflix）受浏览器保护，无法接管
- 极少数强依赖原始 DOM 位置的站点会退回 CSS cover 模式
